The posts address ('Blog' in the header) is where general publications regarding the group, projects, scientific output, and other announcements should be created. There is no hard set of rules for how these should be formatted, but consider using tags in the header for classification:
- Scientific output should have the 'publication' tag.
- News, announcements, or similar should have the 'news' tag.
- If you're publishing something similar to something else, check if it's tagged in the .md frontmatter, and tag it similarly. The specific tag is less important than consistency.

You can always check the existing tags by going to the /tags/ page.

There are no other format considerations for this page, if you have something to share and don't know where to put it, put it here! For future-proofing, I'd recommend keeping the page name as 'shorttitle_author_year'.
